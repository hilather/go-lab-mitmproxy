# CI failure hardening records

When CI fails on a PR or at the end of a PR chain, fix the cause, harden so it is less likely to recur, and add a record here for non-trivial or flaky failures.

Use the root template: [CI-FAILURE-HARDENING-TEMPLATE.md](https://github.com/hilather/go-lab-mitmproxy/blob/main/CI-FAILURE-HARDENING-TEMPLATE.md).

Name files `YYYY-MM-DD-<slug>.md`.
