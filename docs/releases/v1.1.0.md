# LabMITM 1.1.0 Release Notes

Release date: 2026-08-19
Previous release: none (first Git tag). Untagged 1.0 appliance tree: `0ee238b` (notes: [docs/releases/v1.0.0-rc.1.md](https://github.com/hilather/go-lab-mitmproxy/blob/v1.1.0/docs/releases/v1.0.0-rc.1.md)).
Application version: 1.1.0
Configuration versions: labmitm.dev/v1alpha1 (additive 1.1 fields, default off)
REST versions: /v1 plus optional `/compat/flows`
MCP protocol versions: 2026-07-28
Container digest: unpublished (Dockerfile is in-tree; `ghcr.io/hilather/labmitm` is not pushed from this tag)

These notes are curated. They are not a commit list.

LabMITM is a **laboratory intercepting proxy**. It is **not a public** edge proxy and not an attack framework. This tag is created only on a green CI SHA via the Release `tag-gate`.

Residual: [docs/known-limitations.md](https://github.com/hilather/go-lab-mitmproxy/blob/v1.1.0/docs/known-limitations.md).

## Highlights

1.1 is **opt-in additive `labmitm.dev/v1alpha1`**. 1.0 defaults stay HTTP/1.1 + SOCKS-close + no original-destination listener + no `/compat` paths until the operator sets flags and **Reset**s (D51). Native management remains REST `/v1` + MCP `POST /mcp`. **D7 stands:** in-tree proxy, CONNECT Hijack, no third-party MITM library, no Python mitmproxy wrap/exec.

New surfaces on this tag:

- HTTP/2 intercept on the **inner and origin hops** (`spec.protocols.http2.enabled`), codec `internal/http2x` over `golang.org/x/net/http2`. The client-facing proxy port stays HTTP/1.1; `PRI * HTTP/2.0` is still a hard close.
- SOCKS5 CONNECT (optional SOCKS4/4a) multiplexed on `listeners.proxy` when `acceptSOCKS5` / `acceptSOCKS4` are true. NO AUTH only. No BIND/UDP.
- Linux original-destination listener (`spec.listeners.originalDestination`): REDIRECT + `SO_ORIGINAL_DST`. Default image stays UID `65532` / `cap_drop: ALL`. TPROXY stays rejected.
- Bounded mitmproxy-inspired flow REST under `/compat/flows` (`spec.compat.flowREST`). After-auth adapter over `internal/app`. Not mitmweb, not a Python addon VM, not HTTP Basic.
- Inspector shows protocol, HTTP/2 stream id, trailers, SOCKS dest, and original dest.

## Added

- Additive schema fields (all default off): `acceptSOCKS5`, `acceptSOCKS4`, `listeners.originalDestination`, `protocols.http2`, `compat.flowREST`, `maxConcurrentStreams` (0 materializes 100), `match.protocol`. ADRs [0008](https://github.com/hilather/go-lab-mitmproxy/blob/v1.1.0/docs/adr/0008-additive-v1alpha1-11.md)–[0011](https://github.com/hilather/go-lab-mitmproxy/blob/v1.1.0/docs/adr/0011-optional-compat-flow-rest.md). Reserved YAML keys `socks*` / `tproxy` / `transparent` / `mitmproxy*` stay reserved.
- `internal/http2x`: Stream API + `ServeClient`; origin pool never Dials (`DialTLS` nil; second open `refuses redial`). Handshake NextProtos come from the **session snapshot**. Inner CONNECT / Extended CONNECT / websocket Upgrade on h2 is RST `PROTOCOL_ERROR` with no flow. One captured flow per request stream (`HTTP2.StreamID`). Concurrent h2 streams serialize on one HTTP/1.1 origin TCP (`MaxConnsPerHost: 1`; mutex covers `RoundTrip` and full body drain). Replay of an h2 flow is HTTP/1.1 origin-form with leading-`:` names stripped.
- SOCKS5 CONNECT multiplex on the proxy listener (peek replay, `gate.acquire` after a valid CONNECT request, IMDS/hairpin deny do not Dial, IPv6 success BND `::`). Intercept uses `serveInterceptConn` without writing HTTP 200. Metric `labmitm_socks_sessions_total`.
- Linux `originalDestination` listener (default `127.0.0.1:8890`). Dest-IP Dial only. Tagged CONNECT is 400. Origin-form on `:8888` stays 400. Ready uses `OrigDestBound || OrigDestOff`. Overlay: [examples/compose.originaldest.yaml](https://github.com/hilather/go-lab-mitmproxy/blob/v1.1.0/examples/compose.originaldest.yaml). Publishing `:8890` is not transparent (D50).
- Compat flow REST: `GET/DELETE /compat/flows`, `GET/DELETE /compat/flows/{id}`, `POST /compat/flows/{id}/replay`, raw `content/request|response`. JSON array of the newest 200 with `X-LabMITM-Truncated: true` when more exist. Disabled prefix is `404` `not_found`. Same bearer; Basic is 401 Bearer; cookie mutations require CSRF. Contract: [examples/compat/flow-rest-contract.md](https://github.com/hilather/go-lab-mitmproxy/blob/v1.1.0/examples/compat/flow-rest-contract.md). Native catalog stays 30 `/v1` rows. No new MCP tools.
- Inspector protocol badge, stream id, trailers tab, SOCKS dest, original dest. No attack UX.
- `make test-container-originaldest` (skips live REDIRECT without `NET_ADMIN`). `make test-container` still does not require `NET_ADMIN`.

The untagged 1.0 appliance (HTTP/1.1 proxy, lab CA, store, rules, REST `/v1`, MCP, bearer, inspector, hardened image files) is included in this tag. See [docs/releases/v1.0.0-rc.1.md](https://github.com/hilather/go-lab-mitmproxy/blob/v1.1.0/docs/releases/v1.0.0-rc.1.md) for that surface.

## Changed

- Proxy accept mux (D42): Accept never peeks. A per-connection goroutine peeks one byte under `headerTimeout`. Flags off: SOCKS first-byte still closes (1.0). Flags on: SOCKS CONNECT is served on the same listener. `chanListener` hands HTTP (including `PRI`) to `http.Server`. Shutdown: stop accept → close in-peek conns → `chanListener.Close` → `http.Server.Shutdown` → hijack drain.
- 1.1 feature flags are bootstrap + Reset only (D51). `maxConcurrentStreams` rides `replaceAdmission` on **new** TCP sessions. Listener addresses remain reset-only.
- ADR 0002 D8 is superseded **in scope** (HTTP/1.1-only hops). D7 / D16 / D19 / D20 / D21 stand. ADR 0007 D5 “no compat path” sentence is superseded in scope; `/v1`+MCP primacy stands.

## Fixed

- SOCKS error replies (`admission`, IMDS/hairpin deny, dial fail) check the write result (`errcheck`).
- Orig-dest compose overlay skips UID 65532 on OUTPUT REDIRECT and mounts a bearer bootstrap so management can bind. Ready `OrigDestOff` is re-read from the live snapshot.
- 1.0 fixes already on `0ee238b` remain: inner websocket `101` copy, replay hairpin on unspecified binds, flow-body downloads as `application/octet-stream` + attachment + CSP.

## Removed or deprecated

- None. No 1.0 YAML keys were removed. `PRI` on the proxy port is still a hard close. TPROXY / reverse-proxy / Python addon keys stay reserved.

## Security

- Default management auth is still lab static bearer. Unauthenticated `GET /v1/flows` is 401. Compat paths use the same `authenticate` + `authorize` (CSRF on cookie mutations). No HTTP Basic. No OAuth PRM.
- Every new Dial path still resolve-then-guards. SOCKS domain ATYP checks every A/AAAA then Dials a pinned IP. Orig-dest Dials the recovered dest IP only (never Host / `:authority`). Hairpin guards cover both data-plane binds.
- Default image does not gain `CAP_NET_ADMIN`. iptables REDIRECT is host or privileged sidecar only.
- Attack-tool reserved keys stay forbidden (`exploit`, `sslstrip`, `addon`, `pythonaddon`, `publicca`, …).
- `make security-scan` runs govulncheck. Container posture is UID 65532, scratch, no caps.

## Proxy behavior

- Standalone default remains `127.0.0.1:8888`. Lab overlay may publish `:8888`.
- HTTP/1.1 absolute-form + CONNECT Hijack unchanged when 1.1 flags are off. Commands: [docs/02-proxy-semantics.md](https://github.com/hilather/go-lab-mitmproxy/blob/v1.1.0/docs/02-proxy-semantics.md).
- With `protocols.http2.enabled`: minted leaves advertise `h2` then `http/1.1`; origin stays HTTP/1.1 on this tag (transcode). Inner h2 is not a silent tunnel on handshake failure (D20).
- SOCKS is off by default. Transparent orig-dest is a **separate** loopback-default listener (`127.0.0.1:8890`). Docker `-p 8890:8890` alone is not transparent mode.
- Data plane is still unauthenticated. Do not publish without a network boundary.

## Flow-inspector UI

- Still embedded at `/` when `spec.ui.enabled` is true. `enabled: false` 404s `/` and keeps REST/MCP.
- 1.1: protocol badge, HTTP/2 stream id, trailers, SOCKS dest, original dest on list and detail. Bodies stay escaped text / blob download. No fuzzer, repeater, exploit, SSL-strip, Relay, or mitmweb clone.

## Configuration and schema

- Stay on `labmitm.dev/v1alpha1`. Schema: [api/jsonschema/labmitm.dev.v1alpha1.json](https://github.com/hilather/go-lab-mitmproxy/blob/v1.1.0/api/jsonschema/labmitm.dev.v1alpha1.json).

- Orig-dest topologies: shared netns + sidecar iptables, or host network + host REDIRECT. Sidecar has `CAP_NET_ADMIN`; appliance does not.
- `make test-container` unchanged (no `NET_ADMIN`). Optional `make test-container-originaldest`.

## Compatibility and migration

- First Git tag. Operators on untagged `0ee238b` keep 1.0 YAML working without edits (fail-closed defaults).
- To enable 1.1: set the relevant spec fields, Restart or Reset. Reset wipes flows.
- MCP clients still speak `2026-07-28` unless `allowLegacyClients: true`.
- Compat is **not** mitmproxy 11. IDs are ULIDs. No filter DSL, no PUT in-place edit, no mitmweb, no `.mitm` dumpfile.
- HTTP/2 on the **proxy port** is still out. Clients that require h2c CONNECT-to-proxy will still fail.
- Rollback is process restart onto a previous pin. Captured flows are discarded on restart.
- Compose-in to mcp-integration-lab remains D18. Do not claim the lab already runs LabMITM.

## Known limitations

See [docs/known-limitations.md](https://github.com/hilather/go-lab-mitmproxy/blob/v1.1.0/docs/known-limitations.md).

- HTTP/3 / QUIC out. gRPC protobuf codec out. WebSocket **frame** inspect still out (101 + copy).
- No Python mitmproxy / mitmdump / mitmweb wrap. No addon VM.
- No TPROXY in the appliance. No reverse-proxy / ingress. Orig-dest is Linux-only.
- Compat is a bounded subset. No HAR export in this program.
- SOCKS BIND / UDP ASSOCIATE / username-password out. Data plane stays unauthenticated.
- 1.1 flags are Reset-only. Store is still ephemeral, single replica.
- No published image digest, SBOM, or provenance from this tag.
