## Highlights

LabMITM accepts HTTP/1.1 absolute-form requests and CONNECT tunnels from systems under test, optionally intercepts TLS with an in-process lab CA, captures every completed flow, and exposes the same authorized operations over native REST `/v1`, Streamable HTTP MCP `/mcp`, and an embedded flow-inspector SPA on `:8088`. It never wraps, vendors, or execs Python mitmproxy.

## Added

- Single static binary `labmitm`: `serve`, `validate`, `canonicalize`, `healthcheck`, `version`, `help`, `mcp-stdio`.
- In-tree HTTP/1.1 forward proxy (`internal/proxy`): absolute-form GET/POST, CONNECT Hijack + raw tunnel, peekListener SOCKS reject, HTTP/2 preface close, resolve-then-guard (name→IMDS / name→link-local), hop-by-hop strip, WebSocket 101 copy, `HTTP_PROXY` ignored. Interop: `curl --proxy` against localhost.
- In-process lab CA and HTTPS intercept (`internal/tlsmitm`): `ca.mode` generate (ECDSA P-256) or files, per-host leaf mint (SAN=SNI, LRU 256), ALPN `http/1.1` only, default intercept ports `{443}`. Handshake failure stores `Error=tls_handshake` / `upstream_tls` and does not fall back to a blind tunnel. Private keys are never logged. `GET /v1/ca` returns the PEM certificate only.
- Fail-closed `labmitm.dev/v1alpha1` YAML: `KnownFields(true)`, reserved-name reject (socks/tproxy/publicca/mitmproxy/addon/exploit/sslstrip), default materialization, canonical `sha256:` revision.
- Bounded ULID flow store (`internal/store`): stacked `maxFlows`/`maxBytes`/`maxBodyBytes`, `fullPolicy` reject or evict_oldest, Wait, Wipe/ResetTo epoch, optional spill, Pause/Resume/Drop/WaitPaused breakpoint primitives. Store-full still forwards.
- Deterministic first-match rules (`internal/rules`, default-off): `delay` / `drop` / `status` / `header` / `body` / `breakpoint`. Match AND of host (exact or `*.suffix`), pathPrefix, pathExact, method, header. No compiler, no randomness.
- HTTP-less `internal/app.Service`: atomic snapshot, plan/apply, reset that rereads YAML and wipes flows. Live apply: `replaceRules` / `replaceTLS` / `replaceAdmission` / `replaceTargets` / `replaceStoreCaps`.
- Native REST `/v1`: problem+json, HMAC list cursors, wait/resume/drop/replay, cert-only `GET /v1/ca`, plan/apply, health/ready, generated OpenAPI and capability manifest.
- Streamable HTTP MCP at `POST /mcp`: official SDK `v1.7.0`, protocol `2026-07-28`, `mitm_*` tools, `labmitm://` resources, `make test-parity`.
- Lab static bearer. MCP is bearer-only. Session cookie `labmitm_session` + `X-LabMITM-CSRF`. Unauthenticated `GET /v1/flows` is 401.
- Embedded flow-inspector SPA (React/TS + Vite, Node **22.14.0**): login, list, flow detail, status, scoped audit, gated reset. No fuzzer, repeater, exploit, SSL-strip, or Relay. First-party UI (not mitmweb).
- Observability: slog JSON events, hand-rolled OpenMetrics (`spec.observability.metrics.listen`, default `127.0.0.1:9090`), catalog [api/metrics/v1alpha1.json](https://github.com/hilather/go-lab-mitmproxy/blob/v1.0.0-rc.1/api/metrics/v1alpha1.json).
- Hardened image files: `Dockerfile` (scratch, UID 65532, system CA bundle), `examples/compose.smoke.yaml`, `scripts/test-container.sh`. Image is not published from this tag.
- Swap overlay examples: `examples/labmitm.yaml`, MCPJungle JSON, labinfo `labmitm` catalog id. Compose/image pin in mcp-integration-lab is a follow-up.
- GA-001: committed fuzz corpora, `internal/perf` soak (accept N flows, wait, wipe), this notes file, [docs/known-limitations.md](https://github.com/hilather/go-lab-mitmproxy/blob/v1.0.0-rc.1/docs/known-limitations.md), changelog check, Release `tag-gate`.

## Fixed

- None relative to a previous tag. Correctness relative to the design pack is the implementation itself.
- Intercepted CONNECT treats inner `Upgrade: websocket` + `101` as a bidirectional copy (same 1.0 contract as cleartext). Inner `RoundTrip` failure writes `502` and closes both TLS sides instead of leaving the client waiting.
- Replay hairpin reject covers unspecified proxy binds (`:8888`, `0.0.0.0`, `::`) so a lab-overlay replay cannot Dial the unauthenticated data plane on the listen port.
- Flow body downloads (`GET /v1/flows/{id}/request|response`) no longer reflect captured `Content-Type`. They are `application/octet-stream` with `Content-Disposition: attachment` and `Content-Security-Policy: default-src 'none'`.

## Removed or deprecated

- None. First public candidate. No deprecations. There is no predecessor mitmproxy surface to remove.

## Security

- Default management auth is `bearer`. Unauthenticated `GET /v1/flows` is 401. MCP is bearer-only. No OAuth PRM. No HTTP Basic.
- `X-Forwarded-For` is not trusted. Present non-loopback `Origin` is default-deny; missing Origin is allowed.
- Secrets are file references, never inline. Export/audit/logs redact token values. Private keys are never logged. `GET /v1/ca` is cert-only.
- Resolve-then-guard: name→IMDS and name→link-local are default-deny. `HTTP_PROXY` is ignored. Replay never hairpins the proxy listener.
- `make security-scan` runs govulncheck. Container posture is UID 65532, scratch, no caps (`Dockerfile` in-tree; digest unpublished).

## Proxy behavior

- Standalone default: `127.0.0.1:8888`. Lab overlay publishes `:8888`.
- Commands and limits: [docs/02-proxy-semantics.md](https://github.com/hilather/go-lab-mitmproxy/blob/v1.0.0-rc.1/docs/02-proxy-semantics.md). HTTP/1.1 absolute-form and CONNECT Hijack. SOCKS first-byte and HTTP/2 preface are hard closes.
- `tls.intercept: true` mints a lab CA and intercepts listed ports (default `443`). Handshake failure does not fall back to a blind tunnel.
- The proxy data plane is unauthenticated. Do not publish without a network boundary. Recommended `allowHosts` on the lab overlay (`*.lab` + compose DNS names).
- This is a lab intercept appliance. It does not terminate reverse-proxy traffic, speak SOCKS, or inspect WebSocket frames.

## Flow-inspector UI

- Embedded at `/` when `spec.ui.enabled` is true (default). `enabled: false` 404s `/` and keeps REST/MCP.
- Login via bearer → `POST /v1/session`. Cookie is REST-only. No Basic.
- Pages: flow list, flow detail (headers / textual or hex body / TLS / download), status (`ca.spkiSha256` + cert-only CA download), scoped audit, gated reset.
- Live update: `EventSource` `GET /v1/events/stream` with a 3s poll fallback. No mitmproxy WebSocket.
- No fuzzer, repeater, exploit, SSL-strip, or Relay. Required for GA / 1.0 (D13); present in this candidate.

## REST API

- stdlib `net/http` adapter on the management listener (default `:8088`). OpenAPI: [api/openapi/v1.json](https://github.com/hilather/go-lab-mitmproxy/blob/v1.0.0-rc.1/api/openapi/v1.json). Capability table: [api/capabilities/v1.json](https://github.com/hilather/go-lab-mitmproxy/blob/v1.0.0-rc.1/api/capabilities/v1.json).
- Errors are `application/problem+json`. Domain `code` is first-class (`cursor_stale`, `store_over_new_cap`, `target_denied`, …).
- Health live/ready skip auth. Ready requires proxy bound, store initialized, and (management bound or explicitly off).

## MCP API and protocol compatibility

- Pinned protocol **2026-07-28**. Manifest: [api/mcp/v1.json](https://github.com/hilather/go-lab-mitmproxy/blob/v1.0.0-rc.1/api/mcp/v1.json).
- Official SDK `github.com/modelcontextprotocol/go-sdk v1.7.0`. Streamable HTTP at `/mcp` is stateless.
- `spec.management.mcp.allowLegacyClients` default **false** (lab overlay sets true). `subscriptions/listen` stays 2026-07-28 even when the pin is relaxed.
- Tools and `labmitm://` resources come from the shared registry.
- Stdio is a developer adapter (`labmitm mcp-stdio --token-file`) and is not an image entrypoint.

## Configuration and schema

- Strict v1alpha1 decode in `internal/config`. Published schema: [api/jsonschema/labmitm.dev.v1alpha1.json](https://github.com/hilather/go-lab-mitmproxy/blob/v1.0.0-rc.1/api/jsonschema/labmitm.dev.v1alpha1.json).
- Unknown fields, YAML aliases, multi-doc streams, bare numbers, reserved socks/tproxy/publicca/mitmproxy keys, and `upstream.verify` fail closed.
- Canonical export materializes defaults and drops comments. Revision is `sha256:` of canonical JSON. Flow contents do not set `drifted`.
- Reset rereads the bootstrap path (never writes it) and wipes the flow store (only epoch bump). Generate-mode CA rotates on reset.

## Deployment and operations

- `labmitm serve --config PATH` compiles bootstrap and binds the proxy (default `127.0.0.1:8888`). `--management-listen` defaults to `off`; pass `--management-listen=:8088` (or a YAML address plus that flag) to bind management. `SIGTERM` is graceful; `SIGUSR1` is unused.
- Image name `ghcr.io/hilather/labmitm` (Dockerfile in-tree). This tag does not publish a digest. Host ports when composed later: `18888` / `18088`.
- Required CI jobs have no bypass. Tag path is the Release workflow `tag-gate` only.
- `make test-container` builds the image and checks non-root / read-only / no-caps / system CA bundle when Docker is available. Soak: `go test ./internal/perf` (default N=8; local lab target 100 flows/s for 30s).

## Compatibility and migration

- First install only. There is no predecessor application tag.
- Pin config `apiVersion: labmitm.dev/v1alpha1`. Unknown fields fail closed.
- MCP clients must speak `2026-07-28` unless `allowLegacyClients: true`.
- Rollback is process restart onto a previous desired-state pin. Captured flows are discarded on any restart.
- There is no mitmproxy `/flows` / mitmweb / Python addon surface. Do not expect addon scripts to load.
- A later `v1.0.0` tag needs its own `docs/releases/v1.0.0.md` and a green `tag-gate`. **GA / 1.0 is not this rc.** Flow-inspector UI, OBS, image files, and swap overlays are in this tree. Residual: no published image digest, no mcp-integration-lab compose pin, not a public edge proxy.

## Known limitations

See the durable list: [docs/known-limitations.md](https://github.com/hilather/go-lab-mitmproxy/blob/v1.0.0-rc.1/docs/known-limitations.md).

- HTTP/1.1 only. No SOCKS, TPROXY, reverse-proxy, or WebSocket frame inspect.
- No mitmproxy addon / mitmweb compatibility.
- Generate-mode CA rotates on every restart/reset.
- Store-full still forwards. Single replica. Worst-case RSS ≈ 388 MiB.
- MCP has no OAuth PRM. Management is bearer-only.
- Catalog id is `labmitm`. Compose-in is a follow-on lab PR (D18).
- No published image digest, SBOM, or provenance on this candidate. Default soak is 8 flows.
