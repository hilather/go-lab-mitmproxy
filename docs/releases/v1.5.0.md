## Highlights

1.5 is **operator SPA chrome**. [PR #67](https://github.com/hilather/go-lab-mitmproxy/pull/67) lands a split-pane Flows inspector and applies the same dark lab chrome to leftover Login / Status / Audit / Reset **page bodies**. The data plane, catalog, schema, apply verbs, and metrics are **unchanged from [v1.4.0](https://github.com/hilather/go-lab-mitmproxy/blob/v1.4.0/docs/releases/v1.4.0.md)**. Native catalog stays **31** `/v1` rows. `features.get` stays 11 rows. MCP stays **2026-07-28**. No fuzzer, repeater, or exploit UX. **D7 stands.**

What this tag changes:

- Split-pane inspector: the live list stays mounted; selection on `/` and `/flows/:id` drives Request / Response / TLS (Trailers / Frames / gRPC when present).
- Completed raw CONNECT is a tunnel-not-decrypt summary (`why not decrypted: port not in tls.ports:[443]`), not empty HTTP panes. Handshake-failure CONNECT stays an error.
- Shell restyle: primary nav is a sidenav (Sign out is not new). Header chips **live** and **:443 intercept only** are overlay/default copy, not live `tls.ports`.
- Leftover `/login`, `/status`, `/audit`, `/reset` page bodies share that chrome. Status / Audit / Reset / Login **behavior** is unchanged.

## Security

- Unchanged from v1.4.0: lab static bearer; unauthenticated `GET /v1/flows` / `GET /v1/features` / `GET /v1/status` stay 401; no HTTP Basic on management (D6); resolve-then-guard Dial; reserved attack keys stay forbidden; image UID `65532`, scratch, no `CAP_NET_ADMIN`.
- Data-plane `spec.proxy.httpAuth` remains opt-in and **off by default**. Empty `spec: {}` stays an unauthenticated HTTP hop.
- Handshake failure on intercept-eligible CONNECT still does not fall back to a blind tunnel (D20).
- Bearer session, CSRF, skip-link, no token in web storage. Captured HTML stays escaped text. No fuzzer, repeater, exploit, or SSL-strip UX.
- `make security-scan` runs govulncheck.

## Proxy behavior

- Unchanged from v1.4.0. Standalone default remains `127.0.0.1:8888`. Empty `spec: {}` still 101-copies WebSocket, accepts HTTP CONNECT, accepts absolute-form `http://`, and does not 407.
- Data plane is still unauthenticated unless the operator enables `httpAuth`. Do not publish without a network boundary.

## Flow-inspector UI

- Still embedded at `/` when `spec.ui.enabled` is true. `enabled: false` 404s `/` and keeps REST/MCP.
- Split-pane: list stays mounted across `/` and `/flows/:id`. Intercept vs tunnel-not-decrypt chips. Completed raw CONNECT is a tunnel summary, not empty HTTP panes.
- Header **:443 intercept only** and the CONNECT footer/reason sentence are overlay/default copy (`tls.ports:[443]`). They do not read live `replaceTLS` ports from `GET /v1/status` or `GET /v1/state`.
- Status still lists the 11-row `features.get` catalog. Administrators toggle live `setFeature` hop/accept rows. **No Status toggle for `ui.enabled`.** **No Status toggle for `proxy.httpAuth`.** Leftover Status / Audit / Reset / Login **behavior** is unchanged (chrome only).
- Frames tab already existed (1.2). GET-by-id may include `frames[].action`; the Frames tab does not badge `drop` / `block` in this tag.
- No fuzzer, repeater, exploit, SSL-strip, Relay, or mitmweb clone.

## Known limitations

See [docs/known-limitations.md](https://github.com/hilather/go-lab-mitmproxy/blob/v1.5.0/docs/known-limitations.md).

- HTTP/3 / QUIC out. GSSAPI never selected. grpc-web envelope stays opaque. No `.proto` registry.
- Nested inner CONNECT without `:protocol` still RST, **no flow**. Unspecified BIND DST is rejected.
- 1.2 h2c RFC 9113 CONNECT is not `protocols.connect`. 1.2 `extendedConnect` websocket is not `protocols.websocket`.
- No Python mitmproxy / mitmdump / mitmweb wrap. No addon VM.
- No TPROXY in the appliance. No reverse-proxy / ingress. Orig-dest is Linux-only.
- Compat is a bounded subset. No HAR export in this program.
- Data plane stays unauthenticated unless `httpAuth` is enabled. HTTP 407 and SOCKS user-pass are not network boundaries.
- Orig-dest bind, listener addresses, management TLS, `metrics.listen`, and 1.2 nested flags (including `inspectFrames`) are Reset-only. Store is still ephemeral, single replica.
- No Status toggle for `ui.enabled` or `proxy.httpAuth`. Inspector Frames tab does not badge `frames[].action`.
- Header **:443 intercept only** and the CONNECT footer/reason sentence are overlay/default copy. They do not read live `tls.ports`.
- `throttle` is not a connection shaper. Hang holds admission. `payloadContains` cannot see frames larger than the pinned visibility cap.
- No fuzzer, repeater, exploit, SSL-strip, or payload-generator UX.
- No published image digest, SBOM, or provenance from this tag.
- Overlay intercept is HTTPS `:443` only. LabLDAP/TacLab TLS is tunnel-not-decrypt.
