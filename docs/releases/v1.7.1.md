## Highlights

1.7.1 is a **patch** of two Unreleased operator-UI fixes after [v1.7.0](https://github.com/hilather/go-lab-mitmproxy/blob/v1.7.0/docs/releases/v1.7.0.md). They follow post-merge QA of the #85 redesign. The changes are UI chrome and accessibility only, and request bodies are byte-identical. Native catalog stays **31** `/v1` rows. `features.get` stays 11 rows. MCP stays **2026-07-28**. There are no new YAML fields, REST fields, MCP tools, capability IDs, apply verbs or metrics. **D7 stands.**

What this tag changes:

- Contrast, wording, focus and narrow-viewport polish ([PR #87](https://github.com/hilather/go-lab-mitmproxy/pull/87)). White-on-danger fill is now 5.27:1. The Clear confirm and the Reset count wording are corrected, and Reset gets a **Refresh count** button. The Filters popover takes focus when it opens. Viewports at or below 720px stack instead of clipping. The generation inputs have explicit labels, and an inline icon stops the `/favicon.ico` request.
- Mid-width (~768px) follow-up ([PR #89](https://github.com/hilather/go-lab-mitmproxy/pull/89)). The inspector title no longer collapses beside its actions, and layout crushers move to a ≤900px block. Diagnostics/Reset `<time>` tooltips carry the ISO value. Disabled danger controls keep ≥4.5:1 contrast. Filters outside-click focus and the disabled-opener confirm fallback are fixed.

## Added

- None. No new YAML fields, REST paths, MCP tools, capability IDs, apply verbs, or metrics. The **Refresh count** button on Reset re-runs the existing `GET /v1/status` read.

## Changed

- None. No YAML keys, REST paths, MCP tools, capability IDs, apply verbs, or metrics were renamed. ADR 0021 / D80 behaviour (in-page confirm, plan review, D77 off-confirm text) is unchanged.

## Fixed

- Danger-fill contrast. White text on the danger fill uses `--danger-fill: #b04c4c` (5.27:1, was 4.17:1), and the fill keeps at least 3:1 against page surfaces. Disabled danger controls use `--danger-fill-disabled: #5c3033` with white text (≥4.5:1). Outline `.btn-danger:disabled` keeps full danger text without opacity dimming ([PR #87](https://github.com/hilather/go-lab-mitmproxy/pull/87), [PR #89](https://github.com/hilather/go-lab-mitmproxy/pull/89)).
- The Clear confirm states what it deletes, both unfiltered and with server filters. The Reset count is labelled as a snapshot (time, flow count, store generation; "Not live") and has a **Refresh count** button ([PR #87](https://github.com/hilather/go-lab-mitmproxy/pull/87)).
- Filters popover focus. Opening the popover focuses the host field and Escape returns focus to the trigger. An outside click on non-focusable chrome returns focus to the trigger on the completing click ([PR #87](https://github.com/hilather/go-lab-mitmproxy/pull/87), [PR #89](https://github.com/hilather/go-lab-mitmproxy/pull/89)).
- Narrow and mid-width layout. At ≤720px, the rail becomes a row, the flows list stacks above the inspector and the popover is full-width. At ≤900px, the workspace stack, config grid, tables, card heads, list-head rows and popover grid stop crushing at ~768px. The inspector title wraps (`break-word`, flex basis) instead of collapsing beside Replay/Delete. Diagnostics paths wrap in tiles, long flow-list paths ellipsize, and `observability.metrics.publicPath` breaks only after its dots ([PR #87](https://github.com/hilather/go-lab-mitmproxy/pull/87), [PR #89](https://github.com/hilather/go-lab-mitmproxy/pull/89)).
- Diagnostics and Reset `<time>` tooltips carry the same ISO value as `dateTime`, as docs/15 already required ([PR #89](https://github.com/hilather/go-lab-mitmproxy/pull/89)).
- Confirm and plan review fall back to `#app-main` for focus when the opener is disabled or `aria-disabled` ([PR #89](https://github.com/hilather/go-lab-mitmproxy/pull/89)).
- Delete/Clear generation inputs use explicit `for`/`id` label associations. The page declares an inline `data:` icon, so browsers stop requesting `/favicon.ico`; a direct request still 404s, and the server is unchanged ([PR #87](https://github.com/hilather/go-lab-mitmproxy/pull/87)).

## Security

- Unchanged from v1.7.0. The lab static bearer stays, and unauthenticated `GET /v1/flows` / `GET /v1/features` / `GET /v1/status` stay 401. Management TLS enforcement (when configured) is unchanged.
- In-page confirms keep the D77 gated off-confirm text and semantics. Bearer session, CSRF and no token in web storage are unchanged. Captured HTML stays escaped text. The inline `data:` icon needs no CSP change, because the SPA sends no CSP.
- `make security-scan` runs govulncheck.

## Proxy behavior

- Unchanged from v1.7.0. Standalone default remains `127.0.0.1:8888`. Empty `spec: {}` hop behavior, D22-carve gates and bounded HTTP/2 streaming (ADR 0019) are unchanged.

## Known limitations

See [docs/known-limitations.md](https://github.com/hilather/go-lab-mitmproxy/blob/v1.7.1/docs/known-limitations.md).

- Oversized response breakpoints on a shared HTTP/1.1 origin connection hold that connection until the body is consumed or closed (ADR 0019).
- Cleartext HTTP/1.1 response bodies are not flushed per write.
- Management adapter settings still need a restart after configuration changes.
- Request-phase Resume leaves the original breakpoint record `open` and inserts the final capture under a separate ID.
- HTTP/3 / QUIC are out. There is no Python mitmproxy wrap, TPROXY, or reverse-proxy mode. The data plane stays unauthenticated unless `httpAuth` is enabled.
- No published image digest, SBOM, or provenance from this tag.
