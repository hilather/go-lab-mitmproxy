# LabMITM 1.7.4 Release Notes

Release date: 2026-10-26

## Highlights

1.7.4 is a toolchain-only **patch** after v1.7.3 ([PR #104](https://github.com/hilather/go-lab-mitmproxy/pull/104)): Go moves from go1.26.9 to go1.26.10 for GO-2026-6809 (crypto/x509). There is no behavior, API, MCP, configuration or UI change. **D7 stands.**
