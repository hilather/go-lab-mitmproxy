## Highlights

1.6.3 is a **patch** of one Unreleased fix after [v1.6.2](https://github.com/hilather/go-lab-mitmproxy/blob/v1.6.2/docs/releases/v1.6.2.md). Native catalog stays **31** `/v1` rows. `features.get` stays 11 rows. MCP stays **2026-07-28**. No new YAML fields, capability IDs, apply verbs, or metrics. No fuzzer, repeater, or exploit UX. **D7 stands.** D22-carve stays (websocket / connect / absoluteForm default **on**).

What this tag changes:

- HTTP/2 `ServeConn` / `OriginConn` `WINDOW_UPDATE` the connection receive window for DATA that was already buffered when a stream is aborted ([PR #78](https://github.com/hilather/go-lab-mitmproxy/pull/78)). Those unread bytes were counted against the hop-by-hop window and never `onRead`-credited; without the restore, a later POST on the same intercepted CONNECT could stall until `sessionTimeout`. This is the pre-RST / buffered counterpart of the post-RST credit in v1.6.2 ([PR #76](https://github.com/hilather/go-lab-mitmproxy/pull/76)).

## Security

- Unchanged from v1.6.2: lab static bearer; unauthenticated `GET /v1/flows` / `GET /v1/features` / `GET /v1/status` stay 401; no HTTP Basic on management (D6); resolve-then-guard Dial; reserved attack keys stay forbidden; image UID `65532`, scratch, no `CAP_NET_ADMIN`.
- Data-plane `spec.proxy.httpAuth` remains opt-in and **off by default**. Empty `spec: {}` stays an unauthenticated HTTP hop. Enabling 407 on a published bind is still operator risk and is **not** a network boundary.
- Handshake failure on intercept-eligible CONNECT still does not fall back to a blind tunnel (D20).
- Status `replaceTLS` is still a full-subtree replace. Hidden `hosts` / `ca` / `upstream` now come from the same `GET /v1/state` document as `expectedRevision`, so a concurrent REST/MCP TLS edit 409s instead of silently reverting those fields. Generate-mode CA still rotates when the applied TLS spec changes; it no longer rotates a second time solely because the SPA posted a stale subtree with a fresh revision.
- D77 gated off-confirm is unchanged: turning `ui.enabled` off 404s every inspector route on the next UI request. REST/MCP stay up so an administrator can recover without the SPA.
- Bearer session, CSRF, skip-link, no token in web storage. Captured HTML stays escaped text. No fuzzer, repeater, exploit, or SSL-strip UX.
- `make security-scan` runs govulncheck.

## Proxy behavior

- Standalone default remains `127.0.0.1:8888`. Empty `spec: {}` still 101-copies WebSocket, accepts HTTP CONNECT, accepts absolute-form `http://`, and does not 407. D22-carve hop gates stay default **on**.
- Origin-h2 multiplex (`protocols.http2.origin`, Reset-only) still sends request DATA when the inner stream has a body even if content-length is omitted, and still forwards origin trailing HEADERS (including gRPC `grpc-status`). Early-response upload completeness from v1.6.1 is unchanged. Flag-off still transcodes h2→h1 (D44). h2→h1 request trailers toward origin stay dropped (`labmitm_h2_trailer_dropped_total`).
- HTTP/2 header blocks that span `CONTINUATION` still set `END_STREAM` on the opening `HEADERS` (v1.6.2). After RST / forget, connection receive-window credit for DATA that arrives late remains (v1.6.2 / #76).
- After stream abort (silent/hang RST, handler error, origin `RST_STREAM`), `ServeConn` / `OriginConn` now also `WINDOW_UPDATE` the connection receive window for DATA that was already buffered and unread. Those bytes still count against the hop-by-hop window (RFC 9113 §6.9); without the credit, a later POST on the same intercepted CONNECT could stall until `sessionTimeout`. `http2x.outFlow.take` still does not mint a fresh stream send window for a forgotten id (v1.6.1).
- Data plane is still unauthenticated unless the operator enables `httpAuth`. Do not publish without a network boundary.

## Known limitations

See [docs/known-limitations.md](https://github.com/hilather/go-lab-mitmproxy/blob/v1.6.3/docs/known-limitations.md).

- HTTP/3 / QUIC out. GSSAPI never selected. grpc-web envelope stays opaque. No `.proto` registry.
- Nested inner CONNECT without `:protocol` still RST, **no flow**. Unspecified BIND DST is rejected.
- 1.2 h2c RFC 9113 CONNECT is not `protocols.connect`. 1.2 `extendedConnect` websocket is not `protocols.websocket`.
- No Python mitmproxy / mitmdump / mitmweb wrap. No addon VM.
- No TPROXY in the appliance. No reverse-proxy / ingress. Orig-dest is Linux-only.
- Compat is a bounded subset. No HAR export in this program.
- Data plane stays unauthenticated unless `httpAuth` is enabled. HTTP 407 and SOCKS user-pass are not network boundaries.
- Orig-dest bind, listener addresses, management TLS, `metrics.listen`, and 1.2 nested flags (including `inspectFrames`) are Reset-only. Store is still ephemeral, single replica.
- No Status editors for `replaceTargets` / `replaceStoreCaps`. Rules items are a JSON textarea, not a visual rule builder. Reset-only knobs stay Reset-only.
- CONNECT footer / `TUNNEL_REASON` stay overlay/default copy (`tls.ports:[443]`). They do not read live `tls.ports`. `GET /v1/status` has no `tls.ports` field.
- `throttle` is not a connection shaper. Hang holds admission. `payloadContains` cannot see frames larger than the pinned visibility cap.
- No fuzzer, repeater, exploit, SSL-strip, or payload-generator UX.
- No published image digest, SBOM, or provenance from this tag.
- Overlay intercept is HTTPS `:443` only. LabLDAP/TacLab TLS is tunnel-not-decrypt.
