## Highlights

1.4 folds the four issue [#52](https://github.com/hilather/go-lab-mitmproxy/issues/52) implements that landed on `main` after v1.3.0. They are additive `labmitm.dev/v1alpha1` QA knobs. Empty `spec: {}` stays a 1.0 hop process (HTTP/1.1, SOCKS-close, 101-copy, unauthenticated HTTP). Native catalog stays **31** `/v1` rows. Management stays lab static bearer. Data-plane 407 is opt-in and **off by default**. `inspectFrames` stays Reset-only. **D7 stands.**

What this tag adds:

- **D69** (ADR 0014): rule actions `silent`, `hang`, and `redirect`. Issue #52 `http_status` is the existing `status` type (no alias). Live apply stays `replaceRules`.
- **D72–D74** (ADR 0015): `phase: websocket` with actions `drop` / `block` after inspect `101` / inner D63 `:status=200`. `inspectFrames` stays Reset-only. Live path is existing `replaceRules` (and `setFeature rules.enabled` for the master switch).
- **D75** (ADR 0016): `action.type: throttle` paces the winning request or response **body** at `bytesPerSecond`. Headers go out immediately. Live via existing `replaceRules`.
- **D76** (ADR 0017): opt-in HTTP proxy 407 on `listeners.proxy` via `spec.proxy.httpAuth` (default `enabled: false`) and live `replaceHTTPAuth` (8th `KnownOp`). Compact `status.features.httpAuth` (K10 reopen). `features.get` stays 11 rows. No new capability ID.

## Added

- ADR [0014](https://github.com/hilather/go-lab-mitmproxy/blob/v1.4.0/docs/adr/0014-qa-block-modes.md): D69 QA block modes as additive `spec.rules` actions. `silent` writes no HTTP bytes (HTTP/1.1 TCP RST default or FIN; HTTP/2 RST_STREAM `CANCEL` on that stream only — not GOAWAY). `hang` requires `hang.timeout` ∈ [1s, 30s], then the silent close. `redirect` synthesizes 301/302/303/307/308 (default 302) plus required `Location`; request-phase does not Dial. `drop` / `status` stay frozen. Catalog does not grow.
- ADR [0015](https://github.com/hilather/go-lab-mitmproxy/blob/v1.4.0/docs/adr/0015-websocket-frame-rules.md): D72–D74 WebSocket frame rules. `KnownRulePhase` is `request | response | websocket`. First enabled AND-match wins **per inspected frame**. Match fields `opcode`, `direction`, `payloadContains` (no regex, no message reassembly). `phase: websocket` allows only `drop` (omit this frame; continue, including after a dropped `close`) or `block` (close both TCP sides; `Error` empty; `State=completed`). `block` is illegal on `request|response`. Websocket items are valid when `inspectFrames` is false and never fire on the 101-copy path. GET-by-id `frames[].action` is `drop` / `block` (omitted when forwarded).
- ADR [0016](https://github.com/hilather/go-lab-mitmproxy/blob/v1.4.0/docs/adr/0016-rules-throttle-action.md): D75 `action.type: throttle` with `action.bytesPerSecond` (256 B/s–64 MiB/s). YAML and REST apply JSON use an IEC string (`8KiB`). MCP apply JSON is integer bytes on the typed `RuleActionSpec`. `Mutates(throttle)=false` (capture-only tee). Empty / `NoBody` still hits. Illegal on `phase: websocket`. Not a process-wide or per-TCP shared shaper.
- ADR [0017](https://github.com/hilather/go-lab-mitmproxy/blob/v1.4.0/docs/adr/0017-http-proxy-407.md): D76 opt-in HTTP Basic on `listeners.proxy`. Schema `spec.proxy.httpAuth` (`enabled`, `realm` empty→`labmitm-proxy`, file-ref `users[]`). Live `replaceHTTPAuth` via `changes.plan` / `changes.apply`. File-ref users compile into snapshot side table `HTTPAuthUsers` (not Canonical, not export). Check after hop classification / hop gates, before Hijack and before Dial. HTTP/1.1 CONNECT and absolute-form plus client-facing h2c GET and RFC 9113 CONNECT. Orig-dest, inner intercept, Replay, SOCKS, and h2c Extended CONNECT are out. Overlay stays flags-off.
- Metric tokens: `labmitm_rule_hits_total{action}` grows `silent`, `hang`, `redirect`, `block` (websocket `drop` reuses `{action="drop"}`; no `phase` label). `labmitm_proxy_rejected_total{reason=proxy_auth}`. `labmitm_ws_frames_total` still counts forwarded frames only.

The 1.3 appliance (D51' live hop/accept `setFeature`, `features.get`, Status catalog) is included in this tag. See [docs/releases/v1.3.0.md](https://github.com/hilather/go-lab-mitmproxy/blob/v1.3.0/docs/releases/v1.3.0.md).

## Changed

- Canonical JSON of any non-empty `rules.items` list grows three empty match keys (`opcode`, `direction`, `payloadContains`). Empty `spec: {}` revision stays stable.
- Response-phase hits on HTTP/1.1 `101` and inner D63 `:status=200` remain `late_skip`. That is no longer the only post-101 rule story: `phase: websocket` may match inspected frames when `inspectFrames` is on.
- Compact `GET /v1/status` / `mitm_status_get` `features` JSON grows additive `httpAuth` (ADR 0012 K10 reopen). `features.get` stays the frozen 11-row hop/protocol catalog. `setFeature` of `proxy.httpAuth` is `validation_failed`.
- Operator residual ([docs/known-limitations.md](https://github.com/hilather/go-lab-mitmproxy/blob/v1.4.0/docs/known-limitations.md)) records D69 hang-holds-admission, D75 not-a-shaper, D76 default-off 407, and D72–D74 frame-rule pin / visibility residuals.

## Security

- Default management auth is still lab static bearer. Unauthenticated `GET /v1/features` / `GET /v1/status` stay 401. `replaceHTTPAuth` rides `changes.apply` (`mitm.admin` only). Data-plane 407 does not change management auth. HTTP Basic on management is still 401 Bearer (D6).
- Data-plane `spec.proxy.httpAuth` is opt-in and **off by default**. Empty `spec: {}` stays an unauthenticated HTTP hop. Enabling it on a published `:8888` is operator risk and is **not** a network boundary (same sentence as SOCKS user-pass). Overlay examples stay flags-off.
- Successful `Proxy-Authorization` is stripped before origin forward and is not stored on captured request headers. HTTP/1.1 407 is written via `ResponseWriter` with determinate `Content-Length` before Hijack (D19). Client-facing h2c RFC 9113 CONNECT returns stream `407` HEADERS (no AfterAck, no origin Dial) and does not use that `ResponseWriter` helper. Digest / NTLM / Negotiate are out. Basic only.
- HTTP auth digests are a snapshot side table, not Canonical, not export. `setFeature` cannot carry a credential body.
- Handshake failure on intercept-eligible CONNECT still does not fall back to a blind tunnel (D20). `type: silent` is not handshake failure.
- Attack-tool reserved keys stay forbidden. Image UID `65532`, scratch, no `CAP_NET_ADMIN`.
- `make security-scan` runs govulncheck.

## Proxy behavior

- Standalone default remains `127.0.0.1:8888`. Empty `spec: {}` still 101-copies WebSocket, accepts HTTP CONNECT, accepts absolute-form `http://`, and does not 407.
- `silent` / `hang` / `redirect` run on existing request/response phases. Raw CONNECT / SOCKS tunnels still have no HTTP rules. Hang is not breakpoint (not operator-resumable). Hang occupies the HTTP/1.1 `gate.acquire` slot for `hang.timeout`; client-facing h2c and intercepted CONNECT acquire once per TCP.
- `phase: websocket` evaluates only inside the inspect pump after `inspectFrames` Reset. Open inspect sockets, later inner upgrades on a pinned CONNECT, and later h2c streams on a pinned PRI do not see `replaceRules` / `setFeature rules.enabled`. Rules-path close-length-1 is not forwarded (`Error=websocket`). Client-facing h2c Extended CONNECT still has no request/response `matchHit`; frame-phase still runs when inspect is on.
- `throttle` paces body bytes after headers. A long trickle hits existing `sessionTimeout` / `idleTimeout` / `upstreamTimeout` (raise via `replaceAdmission`; `http.Server.IdleTimeout` stays Start-time). Concurrent matching requests each get the full configured rate. WebSocket `101` / CONNECT / SOCKS splice bytes are not paced.
- `httpAuth.enabled: true`: 407 after hop gates, before Hijack / `resolveThenGuard`. Captured `Error=proxy_auth`. Flag-off process is unchanged. Orig-dest tagged CONNECT stays 400 (D57) and is not this gate.
- Data plane is still unauthenticated unless the operator enables `httpAuth`. Do not publish without a network boundary.

## Known limitations

See [docs/known-limitations.md](https://github.com/hilather/go-lab-mitmproxy/blob/v1.4.0/docs/known-limitations.md).

- HTTP/3 / QUIC out. GSSAPI never selected. grpc-web envelope stays opaque. No `.proto` registry.
- Nested inner CONNECT without `:protocol` still RST, **no flow**. Unspecified BIND DST is rejected.
- 1.2 h2c RFC 9113 CONNECT is not `protocols.connect`. 1.2 `extendedConnect` websocket is not `protocols.websocket`.
- No Python mitmproxy / mitmdump / mitmweb wrap. No addon VM.
- No TPROXY in the appliance. No reverse-proxy / ingress. Orig-dest is Linux-only.
- Compat is a bounded subset. No HAR export in this program.
- Data plane stays unauthenticated unless `httpAuth` is enabled. HTTP 407 and SOCKS user-pass are not network boundaries.
- Orig-dest bind, listener addresses, management TLS, `metrics.listen`, and 1.2 nested flags (including `inspectFrames`) are Reset-only. Store is still ephemeral, single replica.
- No Status toggle for `ui.enabled` or `proxy.httpAuth`. Inspector Frames tab does not badge `frames[].action`.
- `throttle` is not a connection shaper. Hang holds admission. `payloadContains` cannot see frames larger than the pinned visibility cap.
- No published image digest, SBOM, or provenance from this tag.
- Overlay intercept is HTTPS `:443` only. LabLDAP/TacLab TLS is tunnel-not-decrypt.
