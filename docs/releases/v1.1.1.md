## Highlights

1.1.1 is a **closeout** of the tagged 1.1 appliance, not a 1.2 expansion. Proxy, TLS intercept, REST `/v1`, MCP, inspector, and 1.1 opt-in flags are unchanged from [v1.1.0](https://github.com/hilather/go-lab-mitmproxy/blob/v1.1.0/docs/releases/v1.1.0.md). **D7 stands.**

What this tag changes:

- SWAP overlay `allowHosts` uses compose DNS (`control`, `taclab`) instead of MCP catalog names (`labldap`, `labtacacs`). Optional `nfs` / `directory` stay commented inside that list. Overlay intercept remains HTTPS `:443` only; LabLDAP/TacLab TLS is tunnel-not-decrypt.
- Onboarding docs (README, START-HERE, docs/14) match the tagged binary: healthcheck is implemented, the image is not “a later PR”, compose-in is vendor+local-build (`labmitm:local`) with `--management-listen=:8088`, and lab smoke is after MCP registration.
- GA-001 + SWAP-001 and M5 are closed with verified tag CI on `a2aa229`. GHCR digest/SBOM/provenance remain unpublished.
- Frozen D18 compose-in has landed in [mcp-integration-lab v0.5.0](https://github.com/hilather/mcp-integration-lab/releases/tag/v0.5.0). This repo’s overlay/docs no longer call that a follow-on. The lab pin stays Git tag **v1.1.0** + image `labmitm:local` (do not bump the lab pin off v1.1.0 for comments). Catalog id remains **`labmitm`**.

## Security

- Unchanged from 1.1.0: lab static bearer; unauthenticated `GET /v1/flows` is 401; no HTTP Basic; resolve-then-guard Dial; reserved attack keys stay forbidden; image UID `65532`, scratch, no `CAP_NET_ADMIN`.
- Overlay `allowHosts` is hostname-only. Listing `control` / `taclab` plus attaching the lab container to `mcplab-shared` lets anyone who can speak HTTP proxy to the published data plane CONNECT-tunnel to those names’ ports (including LabLDAP HTTPS and TacLab listeners). That is a documented expansion versus the 1.1.0 overlay (`labldap`/`labtacacs` failed DNS). Mitigation remains the allowHosts list and the lab network boundary. Default overlay still does **not** list `nfs` / `directory`.
- Overlay intercept is still HTTPS `:443` only (`extraCAFiles: []`). Handshake failure does not fall back to a blind tunnel (D20).

## Proxy behavior

- Unchanged from 1.1.0. Standalone default remains `127.0.0.1:8888`. HTTP/1.1 absolute-form + CONNECT Hijack. 1.1 flags off keep SOCKS-close, no orig-dest, no inner h2. Commands: [docs/02-proxy-semantics.md](https://github.com/hilather/go-lab-mitmproxy/blob/v1.1.1/docs/02-proxy-semantics.md).
- Data plane is still unauthenticated. Do not publish without a network boundary.

## Flow-inspector UI

- Unchanged from 1.1.0. Embedded at `/` when `spec.ui.enabled` is true. Remote inspector Origins are exact `http(s)://host[:port]` matches; loopback Origins are already allowed. Empty `originAllowlist` is enough for `LAB_PUBLIC_HOST=localhost`. Copying LabMail `"*"` still 403s a real Origin.

## Deployment and operations

- `labmitm serve --config PATH` unchanged. `--management-listen` still defaults to `off`; a compose `command:` that copies LabDNS (`["serve", "--config=..."]`) unbinds management and fails HEALTHCHECK. Lab compose **must** pass `--management-listen=:8088`.
- Image name `ghcr.io/hilather/labmitm`. This tag does not publish a digest. Default image: scratch, `USER 65532:65532`, no `NET_ADMIN`.
- mcp-integration-lab v0.5.0 vendors this family at Git tag **v1.1.0** and builds `labmitm:local`. That pin is the **image**, not the overlay bytes: `profiles/default/labmitm/bootstrap.yaml` is a lab-owned copy of the 1.1.1 overlay. Do not recopy from the v1.1.0 `examples/` tree (that tag still has `labldap`/`labtacacs`).
- Tag path is Release `tag-gate` only.

## Compatibility and migration

- Operators on v1.1.0 keep 1.1 YAML working without edits. No required schema migration.
- Labs that copied `examples/labmitm.yaml` from v1.1.0 should replace `labldap`/`labtacacs` with `control`/`taclab` (or copy the 1.1.1 overlay). MCPJungle JSON names are unchanged.
- Overlay `originAllowlist: []` is unchanged; remote inspectors still need an exact Origin in the **lab-owned** bootstrap when `LAB_PUBLIC_HOST` is not loopback. mcp-integration-lab preflight warns (does not fail) in that case.
- Rollback is process restart onto v1.1.0. Captured flows are discarded on restart. Lab compose-in rollback is reverting mcp-integration-lab to v0.4.0.
- HTTP/2 on the **proxy port** is still out.

## Known limitations

See [docs/known-limitations.md](https://github.com/hilather/go-lab-mitmproxy/blob/v1.1.1/docs/known-limitations.md).

- HTTP/3 / QUIC out. gRPC protobuf codec out. WebSocket **frame** inspect still out (101 + copy).
- No Python mitmproxy / mitmdump / mitmweb wrap. No addon VM.
- No TPROXY in the appliance. No reverse-proxy / ingress. Orig-dest is Linux-only.
- Compat is a bounded subset. No HAR export in this program.
- SOCKS BIND / UDP ASSOCIATE / username-password out. Data plane stays unauthenticated.
- 1.1 flags are Reset-only. Store is still ephemeral, single replica.
- No published image digest, SBOM, or provenance from this tag.
- Overlay intercept is HTTPS `:443` only. LabLDAP/TacLab TLS is tunnel-not-decrypt.
