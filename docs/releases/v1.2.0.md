## Highlights

1.2 is **opt-in additive `labmitm.dev/v1alpha1`**. 1.0 defaults stay HTTP/1.1 + SOCKS-close + 101-copy + no original-destination listener + no `/compat` paths until the operator sets flags and **Reset**s (D51). Empty `spec: {}` remains a 1.0 process. Overlay [examples/labmitm.yaml](https://github.com/hilather/go-lab-mitmproxy/blob/v1.2.0/examples/labmitm.yaml) stays flags-off. Native management remains REST `/v1` + MCP `POST /mcp`. Catalog stays 30 `/v1` rows. No new capability IDs. **D7 stands.**

New surfaces on this tag (all default **off**, bootstrap + Reset-only):

- SOCKS5/4 BIND, SOCKS5 UDP ASSOCIATE, and SOCKS5 username/password as **separate** flags beside 1.1 CONNECT-only `acceptSOCKS5` / `acceptSOCKS4`.
- WebSocket RFC 6455 frame inspect on HTTP/1.1 `101`.
- Client-facing h2c on PRI leftover, RFC 9113 CONNECT on that session, and RFC 8441 Extended CONNECT websocket (`:protocol=websocket` only).
- Origin HTTP/2 multiplex when the inner leaf negotiated `h2`, `PUSH_PROMISE` capture-only, and best-effort gRPC protobuf decode.

## Added

- ADR [0012](https://github.com/hilather/go-lab-mitmproxy/blob/v1.2.0/docs/adr/0012-protocol-expansion-12.md) D58–D68.
- Additive schema fields (all default off): `listeners.proxy.acceptBind`, `acceptUDPAssociate`, `acceptUserPass`, `userPass.users[]` (file refs), `protocols.http2.clientCleartext`, `origin`, `extendedConnect`, `capturePush`, `grpcDecode`, `protocols.websocket.inspectFrames`. Reserved YAML keys `socks*` / `tproxy` / `transparent` / `mitmproxy*` stay reserved.
- SOCKS5/4 BIND (`acceptBind`, D58). Listen on the SOCKS control `LocalAddr()` IP only, never `:0` / `0.0.0.0` / `::`. Unspecified DST is rejected (no Listen). Two-reply raw tunnel (`SOCKS.Command="bind"`, `intercepted=false`). Flag-off BIND stays `05 07` / SOCKS4 `91`. Hairpin includes live BIND listen ports.
- SOCKS5 UDP ASSOCIATE (`acceptUDPAssociate`, D59). Relay binds the control IP. Unspecified ASSOCIATE DST is legal. First datagram pins the client UDP source; domain dests LookupIP once then pin; FRAG ≠ 0 dropped; inbound origin floods capped. Flag-off UDP stays `05 07`. No orig-dest UDP, no QUIC.
- SOCKS5 username/password (`acceptUserPass` + `userPass.users[]`, D60). Fail-closed RFC 1929 (no NO AUTH fallback). GSSAPI (`0x01`) is never selected. Digests are a snapshot side table, not Canonical, not export. HTTP hop stays unauthenticated (no `Proxy-Authorization`). Management stays bearer (D6).
- Client-facing h2c on PRI leftover (`protocols.http2.clientCleartext`, D61). Flag-off PRI still hard-closes before `gate.acquire`. Flag-on Hijack (no Write) → `http2x.ServeConn` PrefaceTail (do not re-read the 24-byte preface). Regular h2c GET/POST allowed. `:scheme=https` 400. `http.Server` stays HTTP/1.1-only.
- RFC 9113 §8.5 CONNECT on client-facing h2c (D62). Each CONNECT stream is one origin TCP. No HTTP/1.1 200. Handshake failure RSTs (D20); no DATA tunnel. Orig-dest tagged CONNECT stays 400 (D57). Nested inner CONNECT without `:protocol` still RST, **no flow**.
- RFC 8441 Extended CONNECT websocket (`protocols.http2.extendedConnect`, D63). Inner and client-facing `:protocol=websocket` reuse `internal/wsx`. Success is inner `:status=200`. Other `:protocol` values RST, no flow. Illegal h2 `Upgrade: websocket` still RST, no flow.
- Origin HTTP/2 multiplex (`protocols.http2.origin`, D64) when the inner leaf negotiated `h2`. One CONNECT = one origin TCP. Flag-off keeps D32/D44 h2→h1 transcode. Replay follows the **live** origin flag (off → HTTP/1.1 origin-form with leading-`:` stripped).
- Origin `PUSH_PROMISE` capture-only (`protocols.http2.capturePush`, D65). Inner `EnablePush` stays 0. Promised streams are stored as flows and are **not** forwarded or replayable. Flag-off RSTs the promised id toward origin. Inspector shows parent/promised ids. Metric `labmitm_h2_push_captured_total{result}`.
- Best-effort gRPC protobuf decode (`protocols.http2.grpcDecode`, D66). In-tree length-prefix + protobuf wire tree; no `google.golang.org/protobuf`. Fail-open. grpc-web stays **opaque**. REST/MCP `grpc` on GET-by-id; list omits `messages`. Inspector gRPC tab. Metric `labmitm_grpc_decode_total{result}`.
- WebSocket frame inspect (`protocols.websocket.inspectFrames`, D67). Flag-off stays 101 + copy. Flag-on captures RFC 6455 frames under existing store caps (`maxBodyBytes`, 4096 frames, `{ULID}-ws.body` spill). REST/MCP `websocket` on GET-by-id; list omits `frames`. Inspector Frames tab. Metric `labmitm_ws_frames_total{opcode}`.

The 1.1 appliance (HTTP/2 inner intercept, SOCKS CONNECT, orig-dest, `/compat/flows`, inspector metadata) is included in this tag. See [docs/releases/v1.1.0.md](https://github.com/hilather/go-lab-mitmproxy/blob/v1.2.0/docs/releases/v1.1.0.md) and [docs/releases/v1.1.1.md](https://github.com/hilather/go-lab-mitmproxy/blob/v1.2.0/docs/releases/v1.1.1.md).

## Security

- Default management auth is still lab static bearer. Unauthenticated `GET /v1/flows` is 401. No HTTP Basic. No OAuth PRM.
- Every new Dial path still resolve-then-guards. SOCKS BIND Listen is the control `LocalAddr()` IP only. UDP ASSOCIATE pins the first client source and LookupIP-once dests; every A/AAAA is checked. Hairpin guards cover live BIND listen ports and UDP associate ports. IMDS deny does not Dial or Listen.
- SOCKS user-pass is lab-static file refs, fail-closed, and **not** a network boundary. It does not add HTTP `Proxy-Authorization`. The HTTP hop stays unauthenticated (D17 remainder).
- Handshake failure on intercept-eligible CONNECT still does not fall back to a blind tunnel or DATA-tunnel (D20), including RFC 9113 CONNECT on h2c.
- Attack-tool reserved keys stay forbidden (`exploit`, `sslstrip`, `addon`, `pythonaddon`, `publicca`, …).
- Default image does not gain `CAP_NET_ADMIN`. UID `65532`, scratch, no caps.
- `make security-scan` runs govulncheck.

## Proxy behavior

- Standalone default remains `127.0.0.1:8888`. Lab overlay may publish `:8888`.
- HTTP/1.1 absolute-form + CONNECT Hijack unchanged when 1.1 and 1.2 flags are off. Commands: [docs/02-proxy-semantics.md](https://github.com/hilather/go-lab-mitmproxy/blob/v1.2.0/docs/02-proxy-semantics.md).
- With `protocols.http2.clientCleartext`: PRI leftover becomes h2c. RFC 9113 CONNECT is per-stream origin TCP (no HTTP/1.1 200). Orig-dest tagged CONNECT stays 400.
- With `protocols.http2.origin` and inner leaf `h2`: origin ALPN may be `h2`; one CONNECT remains one origin TCP. Flag-off keeps h2→h1 transcode (D32/D44).
- With `protocols.http2.extendedConnect`: inner and client-facing `:protocol=websocket` reuse `internal/wsx`. Nested inner CONNECT without `:protocol` still RST, no flow.
- SOCKS BIND / UDP / user-pass are off by default. 1.1 CONNECT-only configs do not grow BIND listens, UDP sockets, or a user-pass handshake on upgrade.
- Data plane is still unauthenticated. Do not publish without a network boundary.

## Flow-inspector UI

- Still embedded at `/` when `spec.ui.enabled` is true. `enabled: false` 404s `/` and keeps REST/MCP.
- 1.2: Frames tab (escaped text, never HTML), gRPC tab (escaped protobuf tree), `PUSH_PROMISE` parent/promised ids. Bodies stay escaped text / blob download. No fuzzer, repeater, exploit, SSL-strip, Relay, or mitmweb clone.

## Compatibility and migration

- Operators on v1.1.1 keep 1.1 YAML working without edits. No required schema migration. Empty `spec: {}` is still a 1.0 process.
- To enable 1.2: set the relevant spec fields, Restart or Reset. Reset wipes flows.
- 1.1 `acceptSOCKS5` / `acceptSOCKS4` stay CONNECT-only. BIND / UDP / user-pass require their own flags.
- MCP clients still speak `2026-07-28` unless `allowLegacyClients: true`.
- Compat is **not** mitmproxy 11. IDs are ULIDs. No filter DSL, no PUT in-place edit, no mitmweb, no `.mitm` dumpfile, no frames/gRPC arrays on `/compat`.
- Rollback is process restart onto v1.1.1. Captured flows are discarded on restart.
- Overlay intercept is still HTTPS `:443` only. LabLDAP/TacLab TLS is tunnel-not-decrypt.

## Known limitations

See [docs/known-limitations.md](https://github.com/hilather/go-lab-mitmproxy/blob/v1.2.0/docs/known-limitations.md).

- HTTP/3 / QUIC out. GSSAPI never selected. grpc-web envelope stays opaque. No `.proto` registry.
- Nested inner CONNECT without `:protocol` still RST, **no flow**. Unspecified BIND DST is rejected.
- No Python mitmproxy / mitmdump / mitmweb wrap. No addon VM.
- No TPROXY in the appliance. No reverse-proxy / ingress. Orig-dest is Linux-only.
- Compat is a bounded subset. No HAR export in this program.
- Data plane stays unauthenticated. SOCKS user-pass is not a network boundary.
- 1.1 and 1.2 flags are Reset-only. Store is still ephemeral, single replica.
- No published image digest, SBOM, or provenance from this tag.
- Overlay intercept is HTTPS `:443` only. LabLDAP/TacLab TLS is tunnel-not-decrypt.
